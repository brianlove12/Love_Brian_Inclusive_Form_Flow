F2 · Task and Data Plan

This inventory documents each value collected by the fictional Telepathic Race "Gathering" registration form and explains why it is necessary, how it is submitted, and how unnecessary or sensitive data collection is minimized.

Visible label / question Why necessary now? Required? Native control/type Submitted name/value Autocomplete/inputmode Constraint/instruction Sensitivity and minimization decision
Full name Identifies the person registering for the workshop. Required input type="text" name="full_name" autocomplete="name" required Basic identifying information.
Email address Provides the primary way to send workshop confirmation and participation information. Required input type="email" name="email" autocomplete="email" required; native email validation. Personal contact information.
Phone number Provides an optional way to receive time-sensitive workshop updates or schedule changes. Optional input type="tel" name="phone" autocomplete="tel" None Personal contact information. Kept optional to minimize unnecessary collection.
Workshop session/date Identifies which available workshop session the attendee wants to attend. Required select name="workshop_session" N/A required Low sensitivity.
Attendance method Identifies whether the attendee plans to participate in person or virtually. Required Radio group name="attendance_method" N/A One option required. Low sensitivity.
Accessibility/accommodation request Allows an attendee to request support that would help them participate in the workshop. Optional textarea name="accommodation_request" N/A maxlength="300"; do not include medical diagnoses or private health information. Potentially sensitive. The field is optional and asks only for support needs, not diagnoses.
Workshop policies/terms agreement Confirms that the attendee agrees to follow the workshop participation guidelines. Required input type="checkbox" name="agree_terms" value="yes" N/A required No significant sensitivity.
Book familiarity Helps the workshop presenter understand whether the attendee is already familiar with the workshop material. Optional Radio group name="read_book" N/A None No significant sensitivity.
Number of attendees Indicates how many workshop seats are being requested for the registrant and accompanying guests. Required input type="number" name="attendee_count" N/A required, min="1", max="4", step="1" No significant sensitivity.
